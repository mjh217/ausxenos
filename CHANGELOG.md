# Changelog

Releases use dated version numbers (`vYYYY.MM`). Each GitHub release is archived on Zenodo with its own DOI.

## v2026.11

Initial public release, accompanying Hoggard et al. (2026, *Geochemistry, Geophysics, Geosystems*).

- 11,110 samples/grains from 66 localities (69 localities listed), comprising 11,586 mineral analyses: garnet 7,064; clinopyroxene 4,097; orthopyroxene 222; spinel 116; olivine 87.
- Locality coordinates, host-rock ages and references for all localities.
- `references.bib` with BibTeX entries for all 89 cited references.
